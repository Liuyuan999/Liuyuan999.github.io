# RetailAgent — video narration and storyboard

Narration and storyboard. Approximately 2 minutes.

Paper: https://arxiv.org/abs/2608.28399

## 0:00–0:20

**On screen:** Show two schedules with the same number of long decisions on a single return path.

**Narration:** Two agents can hold a stock equally often and earn different returns because they choose different intervals. RetailAgent studies that timing component.

## 0:20–0:45

**On screen:** Show history, action, and then the subsequent return in sequence.

**Narration:** The LLM sees an anonymized intraday history, chooses long or flat, and then observes the next return. The experiment controls what information is available at decision time.

## 0:45–1:10

**On screen:** Subtract the mean action from each decision and display the timing sum.

**Narration:** The timing metric removes average exposure on each stock-day. It measures whether the agent selects comparatively favorable intervals on the same price path.

## 1:10–1:35

**On screen:** Compare intact text timing with the two shuffle-control values from Table 1.

**Narration:** The principal text condition reports negative timing of 45.7 basis points in magnitude. Shuffling the saved schedule attenuates the effect. The paper also tests how self-authored memory changes persistence.

## 1:35–2:00

**On screen:** Show controlled audit, then transaction costs and market feedback as open study directions.

**Narration:** The action traces reveal sequential structure in the evaluated policies. Measuring timing alongside exposure shows how self-authored memory changes the agent’s decisions.
